# Find My ISS

A live tracker that shows the International Space Station's current position on a map.

**Live demo:** https://findmyiss.bentims.com

## What it does

- Fetches the ISS position every 5 seconds from the Where the ISS at? API
- Moves a marker on an interactive Leaflet map with OpenStreetMap tiles
- Shows latitude, longitude, altitude (miles), velocity (mph), UTC time, and visibility
- Displays a sun or eclipse icon depending on whether the ISS is in daylight

## Built with

JavaScript, HTML, CSS, Leaflet, OpenStreetMap, and the wheretheiss.at API

## Run locally

Clone the repo and open `index.html` in a browser.
